# Basic Network Sniffer Using Python

A beginner-friendly cybersecurity learning project that uses Scapy to capture up to 30 IPv4 packets and display metadata.

## Requirements
- Python 3
- Scapy (`python -m pip install scapy`)
- Npcap on Windows if required for packet capture

## Run
```bash
python sniffer.py
```

Use only on your own device or networks where you have explicit authorization. This program displays packet metadata and payload size; it does not print payload contents.

**Important:** Replace the report's illustrative sample output with your own observed results after running the program.
